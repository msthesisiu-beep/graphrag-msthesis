# Contributing to GraphRAG-MsThesis

This repository documents my Master's thesis research on Knowledge Graph-Augmented RAG for 3GPP technical specifications.

## Research Contribution

The thesis validates that structured Knowledge Graph augmentation improves technical question-answering accuracy by +8.0 percentage points on 3GPP specifications, with favorable computational trade-offs.
